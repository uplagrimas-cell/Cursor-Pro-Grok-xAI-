## ⚙️ 核心操作流程 (Step-by-Step SOP)

### 步骤一：没有 USDT？通过欧意/币安 C2C 购买

1. **注册与实名认证**：
   - 下载安装 **欧意 OKX** 或 **币安 Binance** App，按提示完成基础身份认证。
2. **C2C 快捷买币**：
   - 打开 App 首页，点击 **快捷买币** -> 选择 **C2C 交易**。
   - 筛选支付法币为 **CNY**，目标币种选择 **USDT**。
   - 输入拟购买金额（建议首次购买 **25~40 USDT**，覆盖开卡费及订阅首月费用）。
   - 选择成交率高、支持微信/支付宝/银行卡付款的优质商家，按提示完成转账后点击“已完成支付”。
   - 商家放币后，USDT 将自动存入你的 **资金账户**。

---

### 步骤二：提现 USDT 至 CoreGold 并开立 `5321132` 卡头

1. **获取充值地址**：
   - 登录 [CoreGold 控制台](https://app.coregold.io/signup?invite_code=SA_KKZ8)，点击 **Recharge / 充值**，网络选择 **USDT-TRC20**，复制专属充值地址。
2. **交易所提现**：
   - 打开欧意/币安 App，进入 **资产 -> 提币 -> USDT -> 链上提现**。
   - 粘贴 CoreGold 充值地址，主网选择 **TRC20**，输入数量并确认提现（1~3 分钟内即可自动入账）。
3. **精准开卡**：
   - 资金到账后，在 CoreGold 开卡界面筛选并开立卡头为 **`5321132`** 的美区预付费商业卡。
   - 系统将即时生成 **16位卡号、有效期、CVV 码及自定义美区免税州账单地址**。

### 步骤三：绑定并激活 Cursor Pro / Grok (xAI)

1. **网络环境**：开启全局纯净美区 IP 节点（建议使用独享或家宽节点）。
2. **Cursor Pro 绑定**：
   - 登录 Cursor 官网，进入 `Settings -> Upgrade to Pro`。
   - 在结算界面填入 CoreGold 下发的 **`5321132`** 卡号、有效期、CVV 码及免税州 ZIP 代码（如 `97201`）。
   - 点击提交，即可秒级通过校验完成扣款。
3. **Grok (xAI) 绑定**：
   - 登录 X (Twitter) 或 Grok 独立订阅入口，选择月度/年度订阅计划。
   - 在 Stripe 付款页面输入相同的 `5321132` 卡片要素及免税地址，确认即可无痛激活。

## 🐛 常见错误与排障 (Troubleshooting)

| 错误现象 | 可能原因 | 解决方案 |
| :--- | :--- | :--- |
| **`Card Declined`** | 节点 IP 污染严重或卡内余额不足 | 确认卡片为 `5321132` 卡头，确保卡内 USDT 余额大于订阅金额（预留 $1~$2 摩擦手续费），更换美区独享节点后再试。 |
| **产生额外消费税** | 账单 ZIP 代码使用的高税率地区 | 开卡/绑卡填写的 AVS 地址务必使用 Oregon (OR 97201) 或 Delaware (DE) 等免税州信息。 |
| **续费失败** | 卡内没有留存足额资金 | 保持随用随充策略，在扣款前 1~2 天向 CoreGold 账户充入对应 USDT。 |
